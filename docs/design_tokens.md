### コンポーネント原則

| 要素 | 仕様 |
|---|---|
| 角丸 | 2px（極小） |
| シャドウ | なし、または極微（rgba(0,0,0,0.03) 1px 2px） |
| ホバー | 透過度ダウン（opacity: 0.7）または下線フェードイン |
| ボタン | 塗りつぶし最小、ボーダーのみが基本 |
| 画像 | 大判・白背景・正方形またはやや縦長 |
| 動き | transition: 300ms ease |

### ボタンスタイル例

```
[ Primary ] 黒背景・白字・1pxボーダー
[ Secondary ] 透明・黒字・1pxボーダー
[ Text Link ] 文字＋下線、ホバーで黒太字
```

## 管理画面（ユニバーサルデザイン）

### フォント仕様

```css
font-family: 'Noto Sans JP', -apple-system, BlinkMacSystemFont, sans-serif;
font-weight: 400 (Regular) | 500 (Medium) | 700 (Bold);
```

明朝NG。可読性最優先。

### 文字サイズ可変

ヘッダー右上に **3段階切替UI**:

| 設定 | 基準フォントサイズ | 表示 |
|---|---|---|
| 小（既定） | 14px | 「A-」アイコン |
| 中 | 16px | 「A」アイコン（強調表示） |
| 大 | 18px | 「A+」アイコン |

```html
<!-- ヘッダー右上 -->
<div class="font-size-toggle" role="group" aria-label="文字サイズ">
  <button data-size="sm" aria-pressed="false">A-</button>
  <button data-size="md" aria-pressed="true">A</button>
  <button data-size="lg" aria-pressed="false">A+</button>
</div>
```

CSS変数で全体に反映:

```css
:root {
  --font-base: 14px;
  --font-h1: 24px;
  --font-h2: 20px;
  --font-h3: 18px;
}
[data-size="md"] { --font-base: 16px; --font-h1: 28px; --font-h2: 22px; --font-h3: 19px; }
[data-size="lg"] { --font-base: 18px; --font-h1: 32px; --font-h2: 26px; --font-h3: 22px; }
```

設定は **localStorage に保存**して次回も維持。

### カラーリング（CUD：カラーユニバーサルデザイン準拠）

色覚特性に関わらず識別できる組み合わせ。色だけでなく**アイコン＋テキスト併用**を必須。

#### ステータスカラー

| 状態 | HEX | 用途 | 併用アイコン |
|---|---|---|---|
| 危険 / エラー | #D52941 | 削除・破壊的操作・エラー | ⚠ または × |
| 警告 / 注意 | #F4A300 | 確認が必要・下書き | ⚠ または ! |
| 成功 / 安全 | #2E7D32 | 完了・公開中・OK | ✓ または ● |
| 情報 | #1976D2 | 一般情報・リンク | ℹ |
| 中立 / 待機 | #6C757D | 未対応・下書き | ○ |

参考: <https://jfly.uni-koeln.de/colorset/> CUD推奨配色から色覚特性で識別しやすい組合せを採用。

#### 背景色との組み合わせ（WCAG AA以上）

| 文字色 | 背景色 | コントラスト比 |
|---|---|---|
| #1A1A1A | #FFFFFF | 16.5:1（AAA） |
| #1A1A1A | #F5F5F5 | 14.8:1（AAA） |
| #FFFFFF | #D52941 | 5.1:1（AA以上） |
| #FFFFFF | #2E7D32 | 5.6:1（AA以上） |

すべて WCAG AA（4.5:1以上）クリア。重要な情報は AAA（7:1）を目指す。

### タッチ・クリックターゲット

- ボタンの最小サイズ: **44px × 44px**（WCAG基準）
- 隣接ボタン間の余白: **8px以上**
- リンクは下線必須（色だけでなく形でも識別）

### 状態表現の三重化

すべての状態表示で「**色 + アイコン + テキスト**」の三重化。

例：商品ステータス表示
```
[●] [active]   公開中
[○] [draft]    下書き
[×] [archived] 非公開
```

### フォーム

- ラベルは入力欄の**上**に配置（左ラベルは目線移動が大きい）
- 必須マークは「**※必須**」テキスト＋赤色（赤色だけNG）
- エラーメッセージは入力欄の下に、赤色＋⚠アイコン＋テキスト
- プレースホルダーはあくまで補助、ラベルの代わりにしない

### モーダル・アラート

- 破壊的操作（削除・反映）の確認モーダルは必須
- 「キャンセル」を左、「実行」を右に配置（誤クリック防止）
- 実行ボタンは色 + アイコン + テキストの三重化

### 数字・金額表示

- 3桁区切りカンマ必須
- 単位は数字の直後に半角スペースで分離（例: `¥ 115,500`）
- 右揃え or 等幅フォント（数字の桁数を比較しやすく）
