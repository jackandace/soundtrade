# SOUND·TRADE 運用マニュアル

クライアント向けの管理画面操作ガイドです。
本番 URL: **https://soundtrade.vercel.app/**

最終更新: 2026-05-21

---

## 1. 全体像

| エリア | URL | 誰がアクセス可 |
|---|---|---|
| 公開サイト | `/`, `/catalog`, `/products/[handle]` 等 | 誰でも（無認証） |
| 管理画面 | `/admin/...` | admin_users に登録されたメールアドレスでログイン |

**価格は公開サイト上には一切表示されません**（B2B 問い合わせ獲得モデル）。
価格データは DB に保持し、見積回答のときに担当者から個別案内します。

---

## 2. 管理画面へのログイン

1. https://soundtrade.vercel.app/admin/login にアクセス
2. メールアドレスとパスワードを入力
3. ログインすると `/admin/dashboard` にリダイレクト

> ⚠ パスワードを忘れた場合は、Supabase ダッシュボード（運営側）でリセットを依頼してください。

## 3. 画面別の操作ガイド

### 3-1. ダッシュボード `/admin/dashboard`

**見られる情報:**
- 本日の見積依頼数
- 未対応の依頼数
- 公開中の商品数 / 下書きの商品数
- 直近 5 件の見積依頼

**ここからできること:**
- 「すべて見る」リンクで見積依頼一覧へ移動

---

### 3-2. 商品マスタ `/admin/products`

**できること:**
- 商品一覧表示（最新 100 件、ステータス絞り込み、検索可）
- 商品名・handle・SKU での部分一致検索
- ステータスタブで「公開中 / 下書き / 非公開」を絞り込み
- 商品名をクリック → 編集画面

**個別商品の編集 `/admin/products/[id]`:**
- 商品画像のアップロード・メイン設定・削除（5MB まで、jpg/png/webp/avif）
- 商品名・メーカー・カテゴリ（L1/L2/L3）の編集
- 商品説明（短・長）の編集
- ステータス切替（active = 公開 / draft = 下書き / archived = 非公開）
- 「公開ページを開く」で実際の見え方を別タブで確認

> 💡 商品を一時的に非表示にしたいときは **status を draft に変える**だけで OK。削除する必要はありません。

> ⚠ **商品の新規追加は商品マスタからはできません**。CSV 取込経由のみです（次節）。

---

### 3-3. CSV取込 `/admin/imports`

**新規商品の追加・既存商品の一括更新に使います。** このシステムの中核機能です。

#### 取込フロー（全 4 ステップ）

```
[1] アップロード → [2] エラー確認・修正 → [3] 差分プレビュー → [4] 承認 → 本番反映
```

#### Step 1: アップロード
- 右上「+ 新規アップロード」
- **Pattern A**: Shopify 標準 1 ファイル形式（`shopify_*.csv`）
- **Pattern B**: 4 ファイル分割形式（`products_*.csv` 必須 + `variants_*.csv` / `product_specs_*.csv` 任意）
- BOM 付き UTF-8、1 ファイルあたり 5MB まで

#### Step 2: エラー / 警告の確認
- アップロード完了後、ジョブ詳細画面に自動遷移
- **エラー件数が 0 件**であれば反映可能。1 件でもエラーがあると承認ボタンは出ません
- 各エラー行の「修正 →」をクリック → その場で値を編集 → 保存（自動的に再検証される）
- 修正後でも残ったエラーがあれば、それも 1 件ずつ直す
- 大量にエラーがある場合は CSV 側を直して再アップロードした方が早いことも

エラーコードの主なもの:
| コード | 意味 |
|---|---|
| `MISSING_HANDLE` | Handle 欄が空 |
| `INVALID_HANDLE_FORMAT` | Handle に不正文字（英小文字・数字・ハイフンのみ可） |
| `MISSING_TITLE` | 商品名が空 |
| `MISSING_VENDOR` | メーカー名が空 |
| `PRICE_ZERO_WITH_ACTIVE` | 価格 0 なのに公開ステータス |
| `DUPLICATE_HANDLE` | 同じ Handle が複数行 |
| `DUPLICATE_SKU` | 同じ SKU が複数行 |

#### Step 3: 差分プレビュー
- 「差分プレビュー」ボタン → 「新規追加 / 更新 / 変更なし / エラー」の 4 区分で件数とリストを確認
- update 行は **赤で旧値・緑で新値**がフィールド単位で表示される
- タイル（カウント数字）クリックで絞り込み

> ⚠ **必ずここで差分内容を確認してから次に進んでください**。意図と違う変更が含まれていないかチェック。

#### Step 3.5: 擬似プレビュー（任意）
- 「擬似プレビュー」ボタン → 反映後に公開サイトでどう見えるかをカード形式で確認

#### Step 4: 承認 → 反映
- 「承認 → 反映」ボタン → 確認ページ
- 「⚠ この内容で反映する」→ 最終確認モーダル → 「反映を実行」
- **反映は元に戻せません**（super_admin によるロールバック可能だが手間がかかる）
- 反映前に自動でスナップショットが作成されるので、最悪の場合は復元可能

#### CSV ファイル形式の詳細
- `docs/import_flow_spec.md`（運営側ドキュメント）参照
- 不安な場合は事前に運営側に CSV の中身を確認してもらうのが安全

### 3-4. 見積依頼 `/admin/inquiries`

顧客が公開サイトから送信した見積依頼を管理します。

**できること:**
- ステータス別タブで絞り込み（未対応 / 対応中 / 見積済 / 完了 / キャンセル）
- 受付番号 `ST-YYYYMMDD-XXXX` で識別
- 行クリックで詳細

**詳細画面でできること:**
- 顧客情報・依頼商品一覧の閲覧
- ステータス変更（未対応 → 対応中 → 見積済 → 完了 など）
- 回答した見積金額（税抜）の入力
- 社内メモの記録（**顧客には公開されません**）
- 「保存」で確定

**新規依頼の通知:**
- 顧客が送信すると自動的に管理者メールに通知が届きます
- 件名: `[SOUND·TRADE 管理] 新規見積依頼 ST-XXXXXXXX-XXXX / 〇〇株式会社`
- メールの返信ボタンで顧客に直接返信可能（Reply-To 設定済み）

---

### 3-5. スナップショット `/admin/snapshots`

CSV 反映時に**自動で取られているバックアップ**の一覧と、そこへの**ロールバック**（巻き戻し）操作。

**閲覧:**
- すべてのロールが閲覧可能
- 種別「反映前 / 反映後 / 手動 / 定期」、統計、サイズ、使用済みフラグを確認

**ロールバック実行（super_admin のみ）:**
- 詳細画面の「⚠ このスナップショットに戻す」
- 確認モーダルで **`ROLLBACK`** と半角大文字で入力
- 「ロールバックを実行」で実行
- 実行直前にも自動で snapshot が取られるので、ロールバック自体もやり直し可能

> ⚠ ロールバックは products / variants / product_specs テーブルを**全件**置き換える非常に強い操作です。
> 部分的な巻き戻しはできません。**super_admin に依頼**してください（じぇいさん経由）。

## 4. 操作上の注意事項

### 公開サイトに関する原則
1. **価格は一切表示しません** — 設計思想として価格は完全に非公開。見積依頼から個別案内するモデル
2. **status='active' の商品のみ公開** — draft / archived はカタログに出ません
3. **L2 カテゴリで絞り込みが動く** — 「クラリネット」「サクソフォン」等。L1（管楽器）や L3 は表示専用

### CSV 取込のお作法
1. **反映前に必ず差分プレビュー**を確認 — 思わぬ更新が含まれていないか
2. **エラーは全て解消してから反映** — 強制反映できない仕組みなので安心
3. **大規模な更新は社内合意の上で** — 反映は即時公開
4. **CSV は BOM 付き UTF-8** — Excel で開いて編集する場合は文字化けに注意

### 商品画像
1. **5MB / 枚まで**、jpg / png / webp / avif のみ
2. メイン画像は 1 枚だけ（カードに表示されるもの）
3. メインを削除すると残った先頭が自動的にメインに昇格
4. **画像を変えても CSV 取込は不要**（管理画面で直接管理可）

### 文字サイズ切替
- 画面右上の **A- / A / A+** で 3 段階切替
- 設定はブラウザに保存され次回も維持されます

## 7. 困ったときは

### よくある質問

**Q. 商品を一時的に非表示にしたい**
→ 管理画面 → 商品マスタ → 該当商品 → ステータスを「下書き」にして保存

**Q. CSV 取込でエラーが大量に出る**
→ CSV の形式が違う可能性あり。`shopify_*.csv` または `products_*.csv` の規定フォーマットになっているか確認。判断付かない場合は運営側に CSV を共有して確認

**Q. 間違って CSV を反映してしまった**
→ super_admin（運営側）に連絡してロールバック実行を依頼

**Q. 文字サイズが小さすぎる / 大きすぎる**
→ 画面右上の A+ / A- ボタンで調整可能（ブラウザに記憶される）

**Q. ログインできない**
→ メールアドレス・パスワードを確認。それでもダメな場合は運営側にパスワードリセット依頼

## 付録 A: 用語集

| 用語 | 説明 |
|---|---|
| Handle | 商品の URL スラッグ。英小文字・数字・ハイフンのみ |
| SKU | 商品識別コード。バリアントごとに一意 |
| バリアント | 同じ商品の色違い・調子違いなどのバリエーション |
| ステージング | CSV 取込で本番反映する前に一時保管する領域 |
| スナップショット | DB の全データを保存したバックアップ。ロールバックの起点 |
| 差分プレビュー | これから反映する内容と現状の差を確認する画面 |
| 擬似プレビュー | 反映後に公開サイトでどう見えるかを確認する画面 |
| RLS | Row Level Security。データベース側のアクセス制御 |
