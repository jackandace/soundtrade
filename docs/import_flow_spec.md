## 受付CSVフォーマット

### Pattern A: Shopify標準フォーマット
```
shopify_*.csv（52カラム + メタフィールド）
```
- スキルが生成するメイン形式
- 1ファイルで完結

### Pattern B: 4ファイル分割版
```
products_*.csv     ... 商品マスタ
variants_*.csv     ... バリアント
product_specs_*.csv ... スペック
+ オプション: meta_*.csv ... メタフィールド
```
- データベース直結向け
- 関連ファイルをまとめてZIPアップロード可

### 受付の必須条件
- BOM付きUTF-8（utf-8-sig）
- カンマ区切り
- ファイルサイズ上限: 10MB（1万商品でも十分）
- 1ジョブにつき最大4ファイル

## バリデーションルール

### エラー（反映できない）

| エラーコード | 内容 | 修正方法 |
|---|---|---|
| `MISSING_HANDLE` | Handle が空 | Handleを入力 |
| `INVALID_HANDLE_FORMAT` | Handleに不正文字 | 英数・ハイフンのみに |
| `MISSING_TITLE` | Title が空 | タイトル入力 |
| `MISSING_VENDOR` | Vendor が空 | メーカー名入力 |
| `INVALID_PRICE` | Variant Price が負の数 or 非数値 | 0以上の整数に |
| `PRICE_ZERO_WITH_ACTIVE` | 価格0なのにStatus=active | draftに変更 or 価格入力 |
| `DUPLICATE_HANDLE` | 同じHandleが複数行 | 一意になるよう修正 |
| `DUPLICATE_SKU` | 同じSKUが複数行 | 一意になるよう修正 |
| `INVALID_CATEGORY` | category_l1〜l3 が空または不正 | 既存カテゴリと一致させる |
| `CSV_SCHEMA_MISMATCH` | カラム構成不一致 | 正しいフォーマットで再アップ |

### 警告（反映できるが要確認）

| 警告コード | 内容 |
|---|---|
| `NO_DESCRIPTION` | Body (HTML) または description が空 |
| `NO_IMAGE` | Image Src が空 |
| `LONG_TITLE` | Title が60字超 |
| `NEW_CATEGORY` | 既存カテゴリにないL3カテゴリ |
| `NEW_VENDOR` | 既存にないメーカー（新規追加扱い） |
| `PRICE_CHANGED_LARGE` | 既存比で価格が±30%以上変動 |
| `STATUS_DOWNGRADE` | activeからdraftに変わる商品あり |

### 情報（参考）

| 情報コード | 内容 |
|---|---|
| `NEW_PRODUCT` | 新規商品として追加 |
| `UNCHANGED` | 既存と差分なし、スキップ |
| `META_CHANGED` | メタフィールドのみ変更 |

## 修正UIの設計

### 一覧画面（エラー/警告サマリー）

```
インポートジョブ #2026-05-20-001
状態: 検証完了・修正待ち

[●] 検証結果サマリー
┌──────────────┬─────┐
│ 全行数         │ 294 │
│ 正常           │ 281 │
│ ⚠ 警告         │  9  │
│ ✕ エラー       │  4  │
└──────────────┴─────┘

[●] エラー一覧（修正が必要）
─────────────────────────────────────────────
✕ ERROR  Row 47  YCL-CSGIII
   price_zero_with_active: 価格0なのにStatus=active
   [この行を修正] [draft に変更]
─────────────────────────────────────────────
✕ ERROR  Row 89  YTR-8335WGP
   duplicate_handle: Handle 'yamaha-ytr-8335' が他の行と重複
   [この行を修正] [重複行を削除]
─────────────────────────────────────────────
...
```

### 行修正モーダル

クリックでモーダル展開。エラー箇所がハイライトされ、その場で編集可能。

```
┌─ Row 47 修正 ─────────────────────┐
│                                      │
│  Handle:    yamaha-ycl-csgiii        │
│  Title:     YAMAHA YCL-CSGIII        │
│  Price:    [    0    ] ← ⚠エラー    │
│  Status:   [ active ▼] ← ⚠エラー    │
│                                      │
│  💡 提案: 価格を入力するか、Statusを │
│        draftに変更してください       │
│                                      │
│  [キャンセル]  [この修正を保存]      │
└──────────────────────────────────────┘
```

### 一括修正機能

同じエラーが複数行ある場合は一括変更可能：

```
✕ 同じエラーが12件あります（PRICE_ZERO_WITH_ACTIVE）
[一括で「draftに変更」する]  [個別に対応する]
```

## 擬似プレビューの仕様

### 表示するもの

ステージングデータを **公開サイトのUIで表示**。実サイトに反映する前に、実際の見え方を確認できる。

```
┌────────────────────────────────────┐
│  [プレビューモード - 反映前データ]    │
│  ジョブ #2026-05-20-001              │
│  [× プレビューを閉じる]              │
├────────────────────────────────────┤
│                                      │
│  ▼ 表示モード                         │
│  (●) 全商品  ( ) 新規のみ  ( ) 変更のみ │
│                                      │
│  ▼ 商品一覧（実サイトと同じUI）        │
│  ┌──┐ ┌──┐ ┌──┐                    │
│  │商│ │商│ │商│                    │
│  │品│ │品│ │品│                    │
│  └──┘ └──┘ └──┘                    │
│                                      │
│  各商品クリックで詳細プレビュー        │
└────────────────────────────────────┘
```

### 商品詳細プレビュー

実際の商品ページとまったく同じUIで表示。差分がある場合は**変更前・変更後**を並べて表示するモードも。

```
┌─────────────────┬─────────────────┐
│  変更前（現状）   │  変更後（反映後）  │
├─────────────────┼─────────────────┤
│  価格: ¥484,000   │  価格: ¥495,000   │
│                  │  ↑ 変更されます    │
└─────────────────┴─────────────────┘
```

### 差分ハイライト

スペック表でも、変更されたフィールドだけ**黄色背景で強調表示**：

```
管体材質:    グラナディラ
キー材質:    洋白鍛造銀メッキ
バレル長:    65 mm     ← この値が変わります（旧64.5mm）
```

## 反映処理の安全装置

### 1. 確認モーダル

「反映」ボタンクリック後、必ず確認モーダル：

```
┌─ 本当に反映しますか？ ───────────┐
│                                       │
│  以下の変更が本番サイトに反映されます  │
│                                       │
│  ✓ 新規商品:  12件                    │
│  ✓ 価格変更:  8件                     │
│  ✓ 表示変更:  3件                     │
│  ✓ 削除:      0件                     │
│                                       │
│  反映後、サイトに即時表示されます。    │
│  問題があった場合は、ロールバックも    │
│  可能です（Phase 2機能）。            │
│                                       │
│  [キャンセル]  [反映を実行]            │
└───────────────────────────────────────┘
```

### 2. スナップショット自動作成

反映直前に、現在の products/variants/specs テーブル全体を **自動バックアップ**。
JSONBで保存し、サイズ計測も同時に行う。

### 3. 失敗時のロールバック（Phase 1の最低限）

反映中にエラーが発生したら、自動的にスナップショットから復元（DB トランザクション）。

### 4. 完全ロールバック（Phase 2）

反映後でも、手動で過去のスナップショットに戻せる。super_admin権限のみ。

|---|:---:|:---:|:---:|:---:|
| CSVアップロード | ✓ | ✓ | ✓ | ✓ |

| エラー修正 | ✓ | ✓ | ✓ | ✓ |
| プレビュー閲覧 | ✓ | ✓ | ✓ | ✓ |
| 本番反映承認 | ✓ | ✓ | ✓ | ✕ |
| スナップショット閲覧 | ✓ | ✓ | ✓ | ✕ |
| ロールバック実行 | ✓ | ✕ | ✕ | ✕ |
| ユーザー管理 | ✓ | ✓ | ✕ | ✕ |
| 設定変更 | ✓ | ✓ | ✕ | ✕ |

**clientロール**は「アップロード→検証→修正→承認待ち」までできる。最終反映だけは社内（じぇいさん）が承認する流れ。

## 通知

### メール通知

| イベント | 送信先 |
|---|---|
| CSVアップロード完了（要承認） | 管理者 |
| エラーで停止 | 管理者・アップロード者 |
| 本番反映完了 | アップロード者 |
| 反映失敗（自動ロールバック発動） | 管理者全員 |
| 手動ロールバック実行 | 管理者全員 |

通知先メールは `system_settings.notify.*` で設定可能。

## Phase 1 / Phase 2 切り分け

### Phase 1（1ヶ月以内・必須）

- CSVアップロード
- バリデーション（エラー検出）
- ステージング領域
- 差分プレビュー
- エラー修正UI（基本機能のみ・1行ずつ）
- 擬似プレビュー（商品一覧・詳細のみ）
- 承認 → 反映
- 反映前スナップショット作成（保存のみ）
- 監査ログ記録

### Phase 2（公開後追加）

- 一括修正機能（複数行を一度に修正）
- 完全ロールバック実行UI
- スナップショット閲覧・管理画面
- 通知メールカスタマイズ
- 自動スケジュール反映（指定日時に反映）
- WebSocketによるリアルタイム進捗表示
- インポート履歴の検索・絞り込み
